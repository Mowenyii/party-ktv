# 🎤 局域网 KTV

电脑负责播放，大家用手机扫码点歌。支持 B 站和 YouTube（都实测过），以及其他 yt-dlp 能解析的网站。视频在线中转播放，不保存到硬盘。

## 启动

在 Finder 里双击 `start.command`，或在终端运行 `./start.command`。

- 首次运行会自动创建 `venv` 并安装依赖，大约需要 1 分钟。
- 启动后浏览器会打开播放页 `http://localhost:8000/player`，**先点一下屏幕**（浏览器要求用户点击后才能自动播放声音），然后按 F 全屏。
- 手机和电脑连同一个 Wi-Fi，扫屏幕上的二维码进入点歌页。
- 第一次启动时，macOS 可能会弹窗询问"是否允许 Python 接受传入连接"，选**允许**，否则手机连不上。

## 功能

- 手机端：粘贴视频链接或 App 的分享文字点歌；按住 ☰ 拖动排序，可以置顶、删除、重试；对正在播放的歌可以暂停/继续、重唱、切歌。
- 音量：手机上的 🔉/🔊 按钮调节电脑的系统音量，每次 10%。如果输出设备是 HDMI 等系统音量调不了的情况，会自动改为调节播放器音量。
- 进度条：手机上拖动进度条可以让电脑跳到对应时间。
- 播放历史：手机页底部显示唱过的歌，点"再点"可以重新加入队列，也可以一键清空。同一个视频只保留最近一次（不同链接也能识别为同一个视频）。记录保存在 `history.json`，重启后不丢失。
- 互动按钮：手机上点 👏鼓掌 / 😙口哨 / 🎆烟花 / 👍点赞 / ❤️比心 / 😂哈哈 / 🌹送花 / 🍻干杯，电脑会播放对应声音，屏幕上出现礼花、烟花、飘落的花瓣、碰杯等特效和飘字（带点的人的名字）。声音是浏览器实时合成的，不需要音效文件。每人每 3 秒最多点 5 次。
- 播放端：唱完自动切下一首；左下角显示下一首。点歌二维码会在屏幕上斜着移动、碰边反弹：每首歌开头显示 25 秒，之后每 90 秒出现 15 秒；暂停时，或队列空了且快唱完时一直显示。快捷键：空格暂停，N 切歌，F 全屏。

## 支持多少人

负载测试：1000 个手机同时在线时，一次操作传到所有人约 0.3 秒，服务器 CPU 约 50%，内存约 270MB。实际上限通常取决于家用路由器能连接的设备数（一般几十台），而不是这个程序。

## 原理

`yt-dlp` 只解析真实播放地址 → `ffmpeg` 带上防盗链请求头实时拉流，不转码地封装成 HLS → 浏览器用 hls.js 播放。会同时缓冲当前和下一首，所以切歌基本不用等。断流时会从头重拉并补齐缺的部分，衔接处无缝。临时分片放在系统临时目录，歌曲结束后立即删除。

## 可选环境变量

| 变量 | 作用 | 默认 |
|---|---|---|
| `KTV_PORT` | 端口 | 8000 |
| `KTV_MAX_HEIGHT` | 最高画质，设成 1080 画质更好但更吃网速 | 720 |
| `KTV_HOST` | 手动指定二维码里的 IP（自动识别不对时用） | 自动 |
| `KTV_COOKIES_FROM_BROWSER` | 从浏览器读取登录 cookie，比如 `chrome`。YouTube 提示要登录，或 B 站想要更高画质时用 | 无 |
| `KTV_NO_BROWSER` | 设为 1 时启动后不自动打开浏览器 | 无 |

## 常见问题

- **手机打不开页面**：确认手机和电脑在同一个 Wi-Fi，并检查 macOS 防火墙设置。公司电脑可能禁止外部设备访问，换私人电脑最省事。
- **某首歌一直失败**：先运行 `./venv/bin/pip install -U yt-dlp` 更新解析器，平台改版后 yt-dlp 通常很快会跟进。
